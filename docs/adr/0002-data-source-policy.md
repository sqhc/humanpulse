# ADR-0002：数据源政策（合规白名单）

- 状态：已接受
- 日期：2026-01
- 决策者：sqhc

## 背景

平台聚合新闻、社交与机构数据，涉及版权、平台条款、个人数据与政治敏感内容。个人项目同样需要明确边界，否则会累积无法回滚的法律与运维风险。

## 决策

### 允许的采集方式

| 方式 | 说明 |
| --- | --- |
| RSS / Atom | 首选；用条件请求（ETag / Last-Modified）降低对方压力 |
| 官方开放 API | GDELT、ReliefWeb、UCDP 等免费无鉴权或低门槛接口，按文档限速 |
| 需要注册的 API | Reddit OAuth、Bluesky（App Password）、Mastodon；仅使用官方端点 |
| 开发者手动上传 | 用户对自己提交的材料负责，表单需勾选权利声明 |

### 明确禁止

- **X / Twitter 抓取**：平台自 2025 起转为按量付费 API，未授权抓取存在条款与法律风险。**X 不在路线图内**（个人项目不接受该成本与风险）。
- **绕过反爬**：不针对 Cloudflare / bot management / 登录墙做绕过；`HtmlCollector` 仅对 allowlist 中的公开静态页面启用。
- **规避配额**：不使用多账号轮换、代理池等方式绕过 API 限额。
- **敏感个人数据**：不采集私人联系方式、住址、身份证件、非公开的私人社交内容。

### 数据留存与展示

1. 默认 `STORE_FULLTEXT=false`：只存元数据、短引用与 AI 摘要，**不对外提供全文**。
2. 每条记录保存 `source_url`、`canonical_url`、`fetched_at` 与来源许可备注。
3. 提供 `POST /api/v1/takedown`；收到有效请求后在 7 天内屏蔽来源并删除相关记录，操作写审计日志。
4. 实体库（`entities` / `entity_mentions`）只记录公开报道中出现的公众人物与组织，不建立个人画像；提供实体级删除路径。
5. 已知许可限制：**ACLED 的数据许可仅限非商业/研究用途**，默认不启用；若未来涉及商业化，必须移除该源或取得许可。

### 内容立场

- 平台定位为"记录与观察"：不做立场性结论、不做推荐算法放大、不生成煽动性文案。
- AI 摘要一律标注；`/about` 页面公示数据源清单与政策。
- 提示词与示例输出上线前人工审阅，任何调整走 PR 并升版本号。

## 后果

- 覆盖度低于"全平台抓取"，但可持续、可解释、可回滚。
- 每个新源必须在本 ADR 或 `infra/seed/sources.yaml` 中登记 `license` 字段后才能上线。
